GitHub 文件加速

输入 GitHub 的文件、Release、Gist 或仓库地址，一键生成加速链接

🚀 你的加速链接：

📖 使用说明

本代理基于 Cloudflare Workers 构建。你只需在原 GitHub 链接前加上 本站域名/ 即可。

📦 Releases 下载加速

https://当前域名/https://github.com/user/repo/releases/download/v1.0/file.zip

📄 Raw 源码加速

https://当前域名/https://raw.githubusercontent.com/user/repo/branch/file.txt

⬇️ Git Clone 加速

git clone https://当前域名/https://github.com/user/repo.git

📝 Gist 加速

https://当前域名/https://gist.githubusercontent.com/user/gistid/raw/file.txt
